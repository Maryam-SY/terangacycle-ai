## 3. Sécurité (revue de la conception)

La base est sérieuse (modèle de menaces, BOLA, géorepérage, ré-encodage des images, URL signées, outils de sécurité en CI). Les points ci-dessous sont des **failles ou des manques dans la conception** à corriger avant de coder.

### Critique

| # | Problème | Pourquoi | Correction |
|---|---|---|---|
| S1 | **Idempotence de `POST /v1/reports` = fuite de données (IDOR).** `client_uuid` est unique globalement et un renvoi « retourne l'existant ». | Toute personne qui connaît ou rejoue le `client_uuid` d'un autre obtient son signalement (position, photo, statut). | Ne renvoyer l'existant que si l'appelant est le même auteur (ou le même appareil pour un anonyme) ; sinon 409 sans contenu. Clé unique `(author_or_device, client_uuid)`. |
| S2 | **Hachage du téléphone : « hachage salé » est soit inutilisable, soit cassable.** | Un sel par ligne empêche la recherche par numéro ; un sel fixe et public se casse en quelques minutes (les numéros mobiles sénégalais ne font qu'environ 10⁸ possibilités). | `phone_hash = HMAC-SHA256(clé secrète « pepper » gardée dans le gestionnaire de secrets, numéro normalisé E.164)`. |
| S3 | **Mode démo « code OTP affiché à l'écran ».** | S'il reste actif en production, n'importe qui se connecte avec n'importe quel numéro. | Drapeau `DEMO_MODE` refusé au démarrage si `ENV=production` ; bandeau visible « mode démonstration » ; test automatisé. |

### Important

| # | Problème | Correction |
|---|---|---|
| S4 | Stockage des jetons côté PWA non spécifié (risque `localStorage` + XSS). | Jeton d'accès en mémoire ; refresh en cookie `HttpOnly; Secure; SameSite=Strict` limité à `/v1/auth` ; rotation avec détection de réutilisation (révoquer toute la famille). Refresh stocké **haché** côté serveur. |
| S5 | JWT : algorithme, `iss`/`aud`, clés non spécifiés. | EdDSA ou RS256 (ou HS256 avec clé ≥ 256 bits), liste blanche d'algorithmes, `iss`/`aud`/`exp` vérifiés, `kid` pour la rotation. |
| S6 | OTP : stockage et comparaison non spécifiés. | OTP haché dans Redis, comparaison à temps constant, 5 essais puis invalidation, expiration 5 min, plafond quotidien de coût SMS. |
| S7 | Limitation de débit dans Caddy : l'image standard `caddy:2` **n'a pas** de directive de limitation (il faut un module compilé avec xcaddy). | Faire la limitation dans l'API (Redis) ; configurer les **proxys de confiance** pour lire `X-Forwarded-For`, sinon l'IP est falsifiable ou toujours celle du proxy. |
| S8 | Carte publique des signalements (écran « Tous ») avec positions précises. | La position d'un dépôt peut être le domicile du citoyen : arrondir ou agréger (grille) pour le public, précision complète réservée au staff et au collecteur assigné. |
| S9 | Les photos montrent possiblement des visages ou plaques, visibles par les collecteurs ; le floutage est repoussé après le MVP. | Consigne à l'écran de capture + modération avant exposition aux collecteurs (le flux le permet déjà : `validated` avant mission). |
| S10 | Moindre privilège non appliqué dans le `docker-compose.yml` proposé : l'API se connecte avec `POSTGRES_USER` (super-utilisateur). | Rôle `teranga_app` sans DDL pour l'API, rôle `teranga_migrator` pour Alembic. |
| S11 | `/docs` (OpenAPI) et `/readyz` publics en production. | Désactiver `/docs` hors démo ou le protéger ; `/readyz` sans détails internes. |
| S12 | Reclassement serveur synchrone dans la requête : coût CPU exploitable (déni de service). | Passer par une tâche arq, borner la taille de la file ; la limite de débit protège aussi ce point. |

### Mineur ou à surveiller

- **CSP** : onnxruntime-web demande `'wasm-unsafe-eval'` dans `script-src` ; le prévoir pour ne pas « désactiver la CSP pour que ça marche ».
- **Images Docker et actions non épinglées** (`minio/minio`, `aquasec/trivy`, actions `@v4`) : épingler par version et par SHA dès maintenant (chaîne logicielle).
- **MinIO** : sa distribution communautaire a beaucoup changé en 2025 (console retirée, images moins maintenues). Vérifier l'image utilisable ; alternatives compatibles S3 : Garage, SeaweedFS.
- **Healthcheck** de l'API avec `curl` : absent des images Python minimales ; utiliser `python -c` ou installer `curl`.
- **Pillow** : régler `Image.MAX_IMAGE_PIXELS` explicitement ; les photos HEIC (iPhone) seront refusées : le client compresse en JPEG de toute façon.
- **Gitleaks Action** : gratuite pour un compte personnel, licence requise pour une organisation GitHub.
- **`audit_logs.ip`** : une adresse IP est une donnée personnelle ; fixer une durée de conservation.

## 4. Confidentialité et conformité

| Norme ou cadre | Exigence | État dans la conception | Action |
